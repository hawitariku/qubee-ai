# Qubeessaa AI — Free Afaan Oromo Spell Checker

An AI-powered spell checker for the Afaan Oromo language (Oromiffa), built with FastAPI and machine learning.

## Features
- Spell checking for Afaan Oromo text
- 59,000+ word vocabulary
- Grammar suggestions
- Educational blog about Afaan Oromo language

## Usage
Visit the web interface to check spelling and grammar in Afaan Oromo.
